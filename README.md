自定义代理 Custom Proxy

自定义 HTTP / HTTPS / SOCKS4 / SOCKS5 代理，并可以精确控制哪些网址或 IP 走代理、哪些直连。

功能特性

- 支持 HTTP、HTTPS、SOCKS4、SOCKS5 四种代理协议；
- 可填写代理服务器 IP 或域名，并自定义端口；
- HTTP / HTTPS 代理支持用户名密码认证（自动填充给浏览器）；
- 两种代理范围：
  - **全部流量走代理**：所有网站都经过代理，可配置例外地址；
  - **仅名单走代理**：只有名单命中的网址 / IP 走代理，其余流量直连；

安装方法

### 方法 A：开发者模式加载源码（推荐）

1. 打开 Chrome，访问 `chrome://extensions`；
2. 打开右上角“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择本目录下的 `unpacked` 文件夹。

### 方法 B：安装 .crx

1. 打开 `chrome://extensions` 并开启“开发者模式”；
2. 将 `ProxySwitcher.crx` 拖入该页面并确认安装。

> 较新版本的 Chrome 可能阻止直接拖入 .crx，被阻止时请使用方法 A，两者功能一致。

## 使用方法

1. 点击浏览器工具栏上的扩展图标打开弹窗；
2. 在“外观”中切换界面语言（默认跟随浏览器语言）；
3. 选择代理协议：HTTP / HTTPS / SOCKS4 / SOCKS5；
4. 选择代理范围：
   - **全部流量走代理**；
   - **仅名单走代理**（其余直连）；
5. 填写服务器地址（IP 或域名）与端口；
6. 如需代理认证，填写用户名与密码（仅 HTTP / HTTPS 有效）；
7. 选择“仅名单走代理”时，在“走代理名单”逐行填写目标，例如：

   ```
   example.com
   *.google.com
   1.2.3.4
   10.0.0.0/8
   https://example.com
   ```

8. 选择“全部流量走代理”时，可在“例外”中填写不走代理的地址；
9. 打开右上角开关或点击“保存并应用”，代理立即生效；
10. 点击“停用代理”可恢复为系统代理设置。

代理认证说明

HTTP / HTTPS：支持用户名密码认证，扩展会在代理要求认证时自动填充；
SOCKS4 / SOCKS5：Chrome 原生不支持账号密码认证，请留空认证信息；
由于需要自动填充认证信息，扩展会申请“读取和更改您在所有网站上的数据”权限，这是该功能的系统要求。

走代理名单规则

- 域名：`example.com`（自动匹配主域名及所有子域名）；
- 通配符：`*.google.com`；
- URL 通配符：`*://example.com/*`；
- IPv4 / IPv6：`1.2.3.4`、`2001:db8::1`；
- IPv4 网段：`10.0.0.0/8`；
- 域名互为覆盖：`example.com` 与 `www.example.com` 等效；
- 兼容转义写法：`www\.github\.com` 与 `www.github.com` 等效；
- 多行、逗号、中文逗号、分号均可作为分隔符，`#` 开头视为注释。
